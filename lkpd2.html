LKPD: Input, Output & Operator

Kerjakan berurutan, jalankan setiap kode, dan pahami fungsi tiap barisnya. Jika terjadi error, baca pesan errornya dan cari penyebabnya.

Aktivitas 1 – Prediksi

let a = 10;
let b = 5;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Isi tabel prediksi dan hasil sebenarnya.

OperasiPrediksiHasil sebenarnya
a + b1515
a - b55
a * b5050
a / b22

Apakah prediksi kamu benar? (Ya / Sebagian / Tidak)

Jawaban: Ya, jika prediksi sesuai tabel di atas.

Mengapa?

Jawaban: Karena JavaScript menghitung dengan aturan matematika biasa: + menjumlah, - mengurang, * mengali, dan / membagi nilai variabel a dan b.

Aktivitas 2 – Eksperimen

let a = 20;
let b = 4;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);

Prediksi: a+b, a-b, a*b, a/b, a%b

Jawaban: a+b = 24, a-b = 16, a*b = 80, a/b = 5, a%b = 0

Apa yang kamu temukan?

Jawaban: Operator % (modulus) menghasilkan sisa pembagian. Karena 20 habis dibagi 4, sisanya 0.

Aktivitas 3 – Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
let umur = prompt("Masukkan umur:");
console.log(umur);

Apa fungsi prompt()?

Jawaban: prompt() menampilkan kotak dialog agar pengguna dapat mengetik data (input). Data yang diketik disimpan ke variable dalam bentuk teks (string).

Aktivitas 4 – Menghitung Umur

let tahunLahir = prompt("Masukkan tahun lahir:");
let tahunSekarang = 2026;
let umur = tahunSekarang - tahunLahir;
console.log(umur);

Uji dengan tahun lahir kamu. Umur = ... tahun

Jawaban: Umur = 2026 − tahun lahir. Contoh: tahun lahir 2010 → umur 16 tahun; tahun lahir 2009 → umur 17 tahun.

Aktivitas 5 – Mesin Kasir Mini

let harga = prompt("Masukkan harga:");
let jumlah = prompt("Masukkan jumlah:");
let total = harga * jumlah;
console.log(total);

Uji: Harga = 5000, Jumlah = 4. Total = Rp ...

Jawaban: Total = Rp 20.000 (5000 × 4 = 20000).

Aktivitas 6 – Think Pair Share

THINK: Mengapa membutuhkan variable total?

Jawaban: Variable total menyimpan hasil perhitungan agar bisa ditampilkan, dipakai lagi pada perhitungan berikutnya (misalnya diskon), dan membuat kode lebih mudah dibaca.

PAIR: Jawaban sama? (Ya / Tidak). Jika berbeda, tuliskan.

Keterangan: Diisi sendiri berdasarkan hasil diskusi dengan pasangan.

SHARE: Kesimpulan kelompok.

Contoh kesimpulan: Variable berguna untuk menyimpan hasil proses agar data dapat dipakai ulang dan program lebih rapi.

Aktivitas 7 – Challenge: Warung Digital

Buat program yang meminta nama makanan, harga, dan jumlah. Tampilkan nama, harga, jumlah, dan total. Kembangkan dengan diskon 10%, lalu tampilkan Total, Diskon, dan Total Bayar.

Jawaban: 
let makanan = prompt("Nama makanan:");
let harga = Number(prompt("Harga:"));
let jumlah = Number(prompt("Jumlah:"));
let total = harga * jumlah;
let diskon = total * 10 / 100;
let bayar = total - diskon;
 
console.log("Makanan:", makanan);
console.log("Harga:", harga);
console.log("Jumlah:", jumlah);
console.log("Total:", total);
console.log("Diskon:", diskon);
console.log("Total Bayar:", bayar);
Contoh: Nasi Goreng, harga 15000, jumlah 2 → Total 30000, Diskon 3000, Total Bayar 27000.

Aktivitas 8 – Debugging

let harga = 5000;
let jumlah = 3;
let total harga = harga * jumlah;
console.log(total harga);

Kesalahan:

Jawaban: Nama variable total harga mengandung spasi. Nama variable tidak boleh memakai spasi, sehingga muncul SyntaxError.

Perbaikan kode:

let harga = 5000;
let jumlah = 3;
let totalHarga = harga * jumlah;
console.log(totalHarga); // 15000

Aktivitas 9 – Challenge Mandiri: Kalkulator Tabungan

Buat program yang meminta uang awal, tabungan hari pertama, kedua, dan ketiga, lalu menghitung total.

Jawaban: 
let uangAwal = Number(prompt("Uang awal:"));
let hari1 = Number(prompt("Tabungan hari pertama:"));
let hari2 = Number(prompt("Tabungan hari kedua:"));
let hari3 = Number(prompt("Tabungan hari ketiga:"));
 
let total = uangAwal + hari1 + hari2 + hari3;
console.log("Total tabungan = Rp", total);
Contoh: awal 10000, hari 1 = 2000, hari 2 = 3000, hari 3 = 5000 → Total tabungan = Rp 20.000.
Catatan: Number() wajib dipakai agar + menjumlahkan angka, bukan menyambung teks.

Asesmen Formatif

1. Apa output dari let a = 8; let b = 2; console.log(a + b);?

Jawaban: 10

2. Apa output dari let a = 10; let b = 3; console.log(a % b);?

Jawaban: 1 (sisa dari 10 dibagi 3)

3. Apa fungsi prompt()?

Jawaban: Menampilkan kotak dialog untuk menerima input dari pengguna dan menyimpannya ke variable sebagai teks.

4. Buat program menghitung luas persegi panjang dengan panjang 10 dan lebar 5.

let panjang = 10;
let lebar = 5;
let luas = panjang * lebar;
console.log(luas); // 50
