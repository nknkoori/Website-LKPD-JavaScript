LKPD: String, Number & Konversi Data

Kerjakan mandiri terlebih dahulu, prediksi hasil sebelum menjalankan kode, lalu diskusikan lewat Think Pair Share. Simpan file sebagai lkpd_string_number_nama.js.

Tujuan Pembelajaran

Setelah menyelesaikan LKPD ini, peserta didik mampu:

  1. membedakan String dan Number;
  2. menjelaskan bahwa prompt() menghasilkan String;
  3. menggunakan Number() dan String();
  4. menganalisis kesalahan akibat tipe data;
  5. membuat program input dan perhitungan sederhana.

Aktivitas 1 – Eksperimen 10 + 20

Jangan jalankan terlebih dahulu. Prediksikan hasil:

let a = "10";
let b = "20";
console.log(a + b);

Apa output program?

Jawaban: 1020

Mengapa hasil tersebut terjadi?

Jawaban: Karena "10" dan "20" ditulis dengan tanda kutip, sehingga bertipe String. Pada String, operator + menyambung teks (konkatenasi), bukan menjumlahkan angka.

Apakah a dan b bertipe Number?

Jawaban: Bukan. a dan b bertipe String.

Uji sekarang. Apakah prediksimu benar? Jelaskan.

Jawaban: Ya, hasilnya 1020, bukan 30. Ini membuktikan bahwa nilai di dalam tanda kutip diperlakukan sebagai teks.

Aktivitas 2 – Menemukan Tipe Data

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Jawaban tabel:

Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

Jawaban: String adalah data teks yang ditulis dengan tanda kutip, dan operator + akan menyambungnya. Number adalah data angka tanpa tanda kutip, dan operator + akan menjumlahkannya.

Aktivitas 3 – Konversi String menjadi Number

Perbaiki program agar menghasilkan 30. Gunakan Number():

let a = "10";
let b = "20";
let hasil = __________________________;
console.log(hasil);
Jawaban: 
let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil); // 30
Hasil program: 30.
Sebaliknya, String(10) mengubah angka menjadi teks "10".

Tantangan – Program Hitung Nilai

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input dengan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

Algoritma saya:

Jawaban:
  1. Minta input nilai tugas, UTS, dan UAS dengan prompt().
  2. Ubah ketiga input menjadi Number dengan Number().
  3. Hitung rata-rata: (tugas + UTS + UAS) / 3.
  4. Tampilkan hasil rata-rata dengan console.log().
let tugas = Number(prompt("Nilai tugas:"));
let uts = Number(prompt("Nilai UTS:"));
let uas = Number(prompt("Nilai UAS:"));
 
let rataRata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rataRata);
Contoh: tugas 80, UTS 75, UAS 85 → rata-rata 80.

Think – Pair – Share

1. Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Jawaban: Karena prompt() selalu menghasilkan String. Tanpa konversi, operator + akan menyambung teks, sehingga hasil perhitungan menjadi salah.

2. Apa perbedaan "10" dengan 10?

Jawaban: "10" adalah String (teks) dan 10 adalah Number (angka). "10" + "10" menghasilkan "1010", sedangkan 10 + 10 menghasilkan 20.

3. Apa yang terjadi jika lupa Number()?

Jawaban: Input dianggap teks. Penjumlahan menjadi penyambungan teks (misalnya "10" + "20" menjadi "1020"), sehingga hasil tidak sesuai harapan.

Pair: Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda?

Jawaban: Inti jawabannya sama, hanya susunan kalimatnya yang bisa berbeda karena setiap orang memakai contoh dan bahasa sendiri.

Share: Sampaikan satu temuan penting kepada kelas.

Jawaban: Hasil prompt() selalu String, jadi harus diubah dengan Number() sebelum dihitung.
